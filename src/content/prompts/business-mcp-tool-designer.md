I want an MCP server for my [type of business] so my AI can work with [my spreadsheet / CRM / accounting tool]. Here's what I do every week: [list].
Design the tool list: for each tool give a name, a one-line description written for the AI, the inputs, what it returns, whether it reads or writes, and the safety check it needs (confirmation, limits, logging). Keep it to the 15 tools that matter most. Then list which ones should never be allowed to run without a human saying yes.
