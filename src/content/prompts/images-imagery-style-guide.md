Write an imagery style guide for [brand]. Archetype: [archetype]. Personality: [3 traits]. Palette: [hex codes]. Where images will be used: [website hero, social posts, slides, print].

Cover:
1. Subjects we show and subjects we never show.
2. Lighting and time of day.
3. Color grade, tied to my palette (for example warm golden highlights, deep shadows, no neon).
4. Composition: always leave calm, empty space where text can sit.
5. People: real, candid, no stock-photo handshakes, no people pointing at laptops and laughing.
6. Textures, illustration style and icon style, if any.

Then write 6 image prompts I can paste into any image generator for brand backgrounds: 3 landscape at 16:9 and 3 square at 1:1. Each prompt should describe the scene, the light, the mood, the color grade, the camera angle and where the empty space is. Every prompt must end with: no text, no letters, no logos, no watermarks, no faces.
