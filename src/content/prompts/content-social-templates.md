Design a social template system for [brand] using my brand brain below. [paste brand brain, or palette, fonts, logo rules and voice traits]

I need 5 templates: announcement, quote, quick tip, event or live, testimonial. Sizes: 1080 x 1350 (feed) and 1080 x 1080 (square), plus a 1080 x 1920 story version of the event template.

For each template give me:
1. The layout: where the headline, body, logo and call to action sit, with margins in px.
2. Type sizes and weights for each text element.
3. Color rules: background, text, the one accent.
4. Maximum copy length (headline words, body characters).
5. One example post written in my voice.

Then [choose one]: build them as HTML files I can screenshot / give me step-by-step Canva instructions / give me a Figma frame spec. Keep the logo and footer in the same spot on every template so people recognize me before they read a word.
