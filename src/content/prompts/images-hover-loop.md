Animate this image into a [5]-second loop. One natural motion only: [water falling / fog drifting / embers rising / clouds rolling]. The camera holds almost still, with at most a very slow drift. The last frame must match the first frame so the loop has no visible jump.
No cuts, no shake, no zoom pulses, no flashes. The light stays constant. No text, no logos. Photoreal, like real footage shot on a cinema camera.
